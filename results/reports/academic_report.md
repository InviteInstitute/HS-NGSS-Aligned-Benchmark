## 1. Methods

**Dataset.** A ground-truth question–answer set was generated by **Sonnet 4.6 Thinking** across the **12 NGSS high-school science areas** (71 performance-expectation standards), targeting a balanced mix of question types (recall 33, conceptual 33, applied 34). Every candidate passed three automatic gates before acceptance — near-duplicate removal (rapidfuzz token-set ratio ≥ 88), a high-school readability band (Flesch–Kincaid 5.0–14.0), and an LLM appropriateness check — with 1,770 candidates rejected and regenerated along the way.

**Validation.** Each pair was scored independently by a 3-judge panel (Nemotron 3 Super 120b a12, Gemini Flash 3, OSS 120b). Questions the panel doubted (disagreement or unanimous rejection) were auto-dropped: **1,194 generated → 44 dropped → 1,150 validated** questions used for benchmarking.

**Benchmark & evaluation.** **9 candidate models** each answered every question **3 times** (run 1, run 2, run 3) under a standardized zero-shot protocol (shared high-school system prompt, no per-model tuning). Answers were graded by a single judge (**Nemotron 3 Super 120b a12**, `eval_mode: single`): binary correct/incorrect, plus a 0/0.5/1 rubric for conceptual and applied items. Empty, errored, or refusing responses are scored 0 and reported separately as the refusal rate.

**Scoring conventions used throughout this report.** For every model we report two scores: **single** — accuracy on **run #1 only** (one-shot behavior); and **ensemble** — accuracy after taking the **majority vote across the model's runs** (self-consistency). Accuracies are 0–1 proportions (0.92 = 92%). **Macro** accuracy weights each area equally; **micro** weights each question equally.

<a id="limitations"></a>

## 12. Limitations

- **LLM-generated questions.** The item bank was written by an LLM; such questions may structurally favor LLM respondents, so absolute accuracies should be read with caution.
- **Correctness only.** This measures answer correctness, not pedagogical quality, hallucination rate, or safety.
- **Single evaluation judge.** Grading used one judge (`eval_mode: single`); a triple-judge panel would allow eval-side reliability estimates.
- **Calibration pending.** Judge↔human agreement has not yet been established for this run.
- **Ceiling effects / ties.** Many standards are answered correctly by several models, so 'best model' is often a tie — treat the per-standard picks as 'any of these,' and decide on secondary factors (reading level, token cost, availability).
